# بوت الفعاليات (روليت + مسابقات أصوات + نمو القنوات)

بوت تليجرام بـ Python + aiogram 3 + SQLite.

## التشغيل على Railway (خطوة بخطوة)
1. **BotFather:** أنشئ بوت بـ `/newbot` وخذ التوكن. ثم `/setprivacy` ← اختر بوتك ← **Disable** (ضروري فقط لشرط «التعليق»).
2. **GitHub:** فك الضغط وارفع كل الملفات لمستودع جديد (بدون ملف `.env`).
3. **Railway:** `New Project` ← `Deploy from GitHub repo` ← اختر المستودع.
4. من تبويب **Variables** أضف:
   - `BOT_TOKEN` = توكن البوت
   - `ADMIN_IDS` = ايديك الرقمي (من @userinfobot). تكدر تحط أكثر من واحد بفاصلة.
5. **مهم جداً:** أضف **Volume** للخدمة (Settings ← Volumes) وخل مسار الربط `/data`.
   بدونه قاعدة البيانات تنمسح مع كل نشر جديد وتضيع الإحالات.
6. بعد النشر افتح البوت: `/start` ثم `/admin`.

## أول إعدادات
- **الاشتراك الإجباري العام (مهم):** اجعل البوت **مشرفاً** بقناتك ثم `/addmand @قناتك`. بعدها لا أحد يستخدم البوت قبل الاشتراك.
  إذا ما كان البوت مشرفاً بالقناة، يتعذر فحص الاشتراك ويُسمح للجميع بالمرور (ويصلك تنبيه).
- القناة الإجبارية العامة (قناتك): اجعل البوت مشرفاً فيها ثم `/addmand @قناتك`.
- المكافأة: الافتراضي **5$ لكل 1500 عضو معتمد**. غيّره بـ:
  `/set ref_threshold 1500` و `/set ref_reward 5` و `/set hold_days 7`
- سعر/عدد خاص برابط معيّن: `/linkprice الكود 3.5` و `/linkthr الكود 1000` (الكود يظهر برابط المنظّم).
- مشرفون بصلاحيات محدودة: `/addmod ID` (يديرون الفعاليات والبلاغات والحظر، بدون الدفع والإعدادات).

## كيف يشتغل الاحتساب
- كل منظّم/قناة له رابط `t.me/البوت?start=ref_xxxx`. كذلك أي فعالية تنشئها تجلب أعضاء جدد لصاحبها.
- أول مرة يفعّل شخص البوت: يُسجَّل لصاحب الرابط **مرة وحدة للأبد** (حتى لو غادر ورجع أو دخل برابط ثاني).
- لا يُعتمد العضو إلا بعد: كابتشا + بقائه `hold_days` أيام + عدم حظر البوت.
- عند بلوغ العدد المطلوب يضغط المنظّم «اطلب الصرف» وتوصلك رسالة بأزرار موافقة/رفض. الدفع يدوي منك، ثم تضغط «تم الدفع».
- الرفض يرجّع الأعضاء لرصيد المنظّم.

## ملاحظات تقنية مهمة
- الاحتساب يتم عند **تفعيل البوت** وليس عند الانضمام للقناة، لذلك ما يحتاج صلاحيات خاصة.
- فحص الاشتراك بالقنوات يحتاج أن يكون البوت **مشرفاً** فيها.
- شرط «تعليق»: يُحدَّد الكروب (نفس مجموعة نقاش القناة أو أي كروب ثاني) برابطه، و**لازم البوت يكون مشرفاً فيه** وإلا يرفض البوت الشرط ويُنبَّه المنظّم إذا فقد الإشراف لاحقاً.
- شرط «تفعيل بوت»: يعتمد على ضغط المشارك زر «فعلتها»؛ ما يمكن التحقق منه تلقائياً.
- **شرط الهدية المطورة غير موجود** (يحتاج حساب مساعد MTProto) — انظر FEATURES.md.
- أول دفعة ممكنة بعد مرور `hold_days` على أول المنضمين.

## الاختبار
`python tests/test_core.py` يختبر المنطق الأساسي (الإحالات، الصرف، السحب، التصويت) بدون تليجرام.

## رولت القنوات
من «إنشاء فعالية» اختر «رولت القنوات»: اكتب الرسالة الترويجية، الحد الأدنى لأعضاء القناة، ثم انشر.
المشارك (مشرف/مالك قناة غير قناة الروليت) يرسل قناته، فينشر البوت رسالتك فيها ويُسجَّل له فرصة؛ كل قناة إضافية = فرصة إضافية.
ملاحظة: رابط `tg://openmessage` بإشعارات الانضمام يعتمد على نسخة تطبيق تليجرام عند المستلم؛ اليوزر والايدي يظهران بجانبه دائماً.
